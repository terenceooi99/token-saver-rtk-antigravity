# Contributing to Token Saver (RTK) for Antigravity IDE

Contributions, issues, and feature requests are welcome!

## Development Workflow
1. Fork and clone the repository.
2. Ensure you have the `rtk` binary installed (`winget install rtk-ai.rtk` or `brew install rtk-ai/tap/rtk`).
3. Make changes to skills, rules, or the extension code.
4. Test in Antigravity IDE or VS Code:
   - In Antigravity: Run `scripts/install-skills.ps1` to test global slash commands.
   - In VS Code / OpenVSX: Press `F5` to launch Extension Development Host.
5. Submit a pull request.
